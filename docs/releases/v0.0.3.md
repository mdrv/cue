## v0.0.3

Section-aware prompter release. Adds flat per-cue section tags with sticky headers and inline dividers, plus presenter notes, stable cue ids with deep-linking, pronunciation hints, configurable focus emphasis, and per-speaker color borders. `cue list` now groups output by section.

This is the first release that meaningfully expands the transcript model itself. Every addition is optional and backward-compatible — v0.0.2 transcripts render unchanged.

### Added

**Transcript model**

- `Cue.section?: string` — flat per-cue section tag. Boundaries emerge when consecutive cues carry different values. Empty strings rejected.
- `Cue.notes?: string` — presenter notes. Off-stage panel, toggled by `N`. Visibility persisted per transcript title.
- `Cue.id?: string` — stable handle for deep-linking. Must be unique across the transcript; duplicates fail validation with `cue.id "x" appears at cues #N, #M`.
- `Cue.say?: string` — pronunciation hint. Renders as small dim italic text above the cue text.
- `loadTranscript` now runs a post-parse `checkUniqueIds` pass that emits rich CueError issues (richer than Zod's `superRefine` would).

**Config**

- `CueConfig.focusStyle: 'opacity' | 'underline' | 'box'` (default `'opacity'`). Adds extra emphasis on the focus cue on top of the existing size/color gradient.
- `FocusStyle` and `Anchor` types exported from the public API.

**Frontend**

- Sticky section bar at the top of the stage (or bottom for `anchor: 'bottom'`) showing the current section name, a `position / total` counter, and a mini progress bar. Hidden entirely when the transcript has no sections.
- Inline section dividers rendered within each column at every section change (thin horizontal rule with the section name in uppercase letter-spaced caps). In duet mode each column tracks its own boundaries.
- `[` / `]` keyboard shortcuts to jump to the previous / next section boundary.
- Presenter notes panel — fixed top-right, hidden by default, `N` toggles. Shows the current cue's notes plus a preview of the next cue that has notes. Visibility persisted in `localStorage` (`cue:<title>:notes`).
- Pronunciation hints rendered above cue text.
- `?id=welcome` URL deep-linking — on load the prompter jumps to the first cue whose `id` matches.
- Focus style modes — `underline` adds a 3px accent bottom border, `box` adds a 2px accent border all around. `opacity` (default) leaves the v0.0.2 look unchanged.
- Speaker color border on every cue (was focus-only). The colored left edge comes from `SpeakerConfig.color` and is now visible on all cues via an inset box-shadow.

**CLI**

- `cue list` plain output now groups cues by section. Each group gets a `# SectionName` header and a `— section:` subtotal line. When the transcript has no sections, output matches the v0.0.2 flat format.
- `cue list --json` adds a top-level `sections: [{ name, start, end, count, speakers, totalDuration }]` array and per-cue `section`, `notes`, `id`, `say` fields.
- Inline cue tags in `list` rows: `#<id>`, `say:<text>`, and a `notes` marker.

**Public API**

- `FocusStyle` type exported from `src/index.ts`.

**Examples**

- `examples/demo.ts` rewritten to showcase all v0.0.3 features: three sections (`Intro`, `Main`, `Outro`), two ids (`welcome`, `idea`), three cues with notes, one cue with a pronunciation hint.

**Tests**

- `tests/schema.test.ts` — added 2 tests (cue schema accepts the new optional fields; rejects empty `section` and `id` strings).
- `tests/load.test.ts` — added 2 tests (`loadTranscript` preserves the new fields; rejects duplicate ids with the proper CueError code and message).
- `tests/fixtures/valid.ts` updated to carry `section`, `id`, and `notes`.
- `tests/fixtures/dup-ids.ts` added — two cues sharing `id: 'dup'` for the uniqueness test.
- Total: **24 pass / 0 fail** across 4 files (schema 9, estimate 3, load 5, markdown 7).

### Changed

- Every cue now carries a left-edge color from its speaker's `SpeakerConfig.color`. Previously this was only shown on the focus cue.
- `.cue` has a permanent `padding-left: .75rem` to make room for the colored edge on all cues.
- `cue list` no longer treats `duration: 0` as timed (now requires `> 0`); matches the schema's positive-integer rule.

### Fixed

- None. No bugs were closed in v0.0.3; the work was purely additive.

### Known issues

- **BUG-001** — hot-reload re-fetch race under rapid edits (under 150ms debounce). Unchanged from v0.0.1.
- **BUG-003** — SSE reconnection flicker on Firefox. Unchanged from v0.0.1.
- **BUG-004** — markdown link regex truncates URLs containing a literal `)`. Workaround: percent-encode as `%29`. Unchanged from v0.0.2.
- **BUG-005** — markdown rendering is inline-only. Block-level support deferred to v0.1.0. Unchanged from v0.0.2.
- **BUG-006** — `cue list --json` omits `estimated` fields without `--wpm`. Unchanged from v0.0.2.
- **BUG-007** (new) — sections, notes, ids, pronunciation hints, focus styles, and speaker-color borders are covered by unit and CLI tests but **not yet by automated browser tests**. Visual verification has been manual via the Firefox MCP. Playwright is scheduled for v0.1.0.

- Image cue type (`{ image: 'url' }`) — v0.1.0.
- Countdown timer overlay — v0.1.0.
- `cue export --format html` — v0.1.0.
- Playwright browser tests — v0.1.0.
- Script mode (render notes as the primary view) — v0.1.0, built on top of v0.0.3 notes.
- Plugin system, config linting, docs site, mobile layout, i18n/RTL/CJK — v1.0.0.
