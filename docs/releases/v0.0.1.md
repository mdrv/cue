## v0.0.1

First prototype slice. Loads a `.ts` transcript file, validates and normalizes it, serves a dual-column teleprompter frontend with look-ahead focus, hybrid timing (auto-advance + manual keypress), and hot-reload via SSE. CLI provides `cue <file>`, `cue check`, and `cue init`.

### Added

**Foundation**

- `CueError` with codes (`CONFIG`, `PARSE`, `LOAD`, `SERVE`, `GENERIC`) and `cueError()` factory.
- LogTape setup (`initLogger`) with pretty console sink, root category `['cue']`, singleton guard.
- Type modules for config, transcript, and errors.

**Config** (`src/config/`)

- `CueConfig`, `ThemeConfig`, `SpeakerConfig` types with `DEFAULT_CONFIG` (dark theme) + `LIGHT_THEME`.
- Zod schema for CueConfig validation (dark + light theme defaults).
- `defineConfig()` helper for user-facing config authoring.
- `loadConfig()` with resolution order: `--config` → `./.cue/cue.ts` → `~/.config/cue/cue.ts` → defaults.
- `cue init` writes sample config from template.

**Transcript** (`src/transcript/`)

- `Cue`, `Transcript`, `TranscriptMeta`, `Speaker` types. Defaults: `speaker='main'`, `wpm=160`.
- Zod schema accepting bare array or `{meta, cues}` object. Normalizes speaker default.
- `parseTranscriptFile` via dynamic import with `pathToFileURL`.
- `estimateDuration` (word-count to ms) and `estimateDurations` (fill missing only).

**Server** (`src/server/`)

- `serveTranscript` — Bun.serve with routes: `GET /` (HTML), `GET /api/transcript` (JSON), `GET /events` (SSE).
- `ReloadHub` — pub/sub for SSE with keepalive pings and `hello`/`reload` events.
- `Bun.watch` file watcher with 150ms debounce for hot-reload.
- `openBrowser` cross-platform (macOS/Linux/Windows).

**Frontend** (`src/frontend/`)

- `renderPage` — builds full HTML string with inline CSS+JS and `window.__CUE__` JSON bootstrap.
- `app.js` — vanilla browser JS: look-ahead rendering (focus/next/next2/prev/past CSS classes), duet two-column layout routing speakers to columns, auto-advance via duration + setTimeout, keyboard controls (Space/→/←/P/R/F/T/+/-/?), dark/light theme toggle (T key), SSE reconnect for hot-reload, click-to-advance.

**CLI** (`src/cli/`) — `cue` command via CrustJS

- Global flags: `--debug/-d`, `--json/-j`, `--config`.
- Root flags: `--port/-p`, `--open/--no-open`, `--duet`, `--wpm`, `--estimate`.
- `cue <file>` — loads transcript, estimates if requested, starts server.
- `cue check <file>` — validates transcript, prints summary.
- `cue init [--force] [--path]` — writes sample config file.
- Help + version plugins wired. CueError-aware top-level catch.

**Public API** (`src/index.ts`)

- Re-exports: errors, log, config types/helpers, transcript types/schema/load/estimate, VERSION.

**Tests** (`tests/`)

- 13 unit tests across `schema.test.ts` (7), `estimate.test.ts` (3), `load.test.ts` (3). All pass.

### Known issues

- BUG-001: Hot-reload re-fetch race on rapid edits.
- BUG-002: Frontend font size not persisted across hot-reload.
- BUG-003: Firefox SSE reconnection flicker.
